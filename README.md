# 🎓 Liceum Management System

Веб-приложение для управления учебным процессом в лицее. Система предоставляет инструменты для администраторов, классных руководителей и учеников для управления расписанием, домашними заданиями, рейтингами и другими аспектами учебного процесса.

## 📋 Описание

Liceum Management System — это полнофункциональная платформа для управления лицеем, которая включает в себя:
- Систему управления пользователями (администраторы, классные руководители, ученики)
- Управление расписанием уроков
- Систему домашних заданий с возможностью загрузки файлов
- Рейтинговую систему для оценки успеваемости
- Систему уведомлений и событий
- Управление учителями и предметами
- Интерактивную карту лицея

## ✨ Основные возможности

### Для администраторов
- ✅ Управление пользователями (добавление, удаление, изменение)
- ✅ Массовая загрузка пользователей из файлов

- ✅ Управление классами и предметами

### Для классных руководителей
- ✅ Просмотр и проверка домашних заданий своего класса
- ✅ Отправка уведомлений ученикам
- ✅ Создание событий для класса
- ✅ Управление рейтингом учеников
- ✅ Возможность банить учеников за нарушения
- ✅ Изменение логинов и паролей учеников

### Для учеников
- ✅ Просмотр расписания уроков
- ✅ Отправка домашних заданий (текст и файлы)

- ✅ Получение уведомлений и информации о событиях

## 📦 Установка

### Предварительные требования
- Node.js (v14 или выше)
- MongoDB (v5 или выше)
- npm или yarn

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Rimashi/project_for_liceum.git
cd project_for_liceum
```

2. Установите зависимости:
```bash
npm install
```

3. Настройте переменные окружения в файле `.env`:
```env
PORT=3000
JWT_ACCESS_TOKEN=your_secret_access_token
JWT_REFRESH_TOKEN=your_secret_refresh_token
ADMIN_PASS=your_admin_password
```

4. Убедитесь, что MongoDB запущен:
```bash
# Для Linux/MacOS
sudo systemctl start mongodb

# Для Windows
net start MongoDB
```

5. Запустите приложение:
```bash
# Для разработки
npm run dev

# Для продакшена
npm start
```

6. Откройте браузер и перейдите по адресу:
```
http://localhost:3000
```

## 🔧 Конфигурация

### Настройка базы данных

По умолчанию приложение подключается к локальной MongoDB:
```javascript
const url = 'mongodb://127.0.0.1:27017/liceum-app';
```

**Рекомендация для продакшена:** Для повышения безопасности рекомендуется вынести строку подключения в переменные окружения. Добавьте в `.env`:
```env
MONGODB_URL=mongodb://127.0.0.1:27017/liceum-app
```

И измените в `server.js`:
```javascript
const url = process.env.MONGODB_URL || 'mongodb://127.0.0.1:27017/liceum-app';
```

### Создание администратора

При первом запуске приложение автоматически создает пользователя `admin` с паролем, указанным в файле `.env` (переменная `ADMIN_PASS`).

Логин: `admin`  
Пароль: значение из `ADMIN_PASS` в `.env`

## 🚀 Использование

### Вход в систему

1. Откройте главную страницу (`http://localhost:3000`)
2. Введите логин и пароль
3. В зависимости от роли, вы будете перенаправлены на соответствующую страницу:
   - Администратор → `/admin`
   - Классный руководитель → `/leader`
   - Ученик → `/student`

### API эндпоинты

#### Аутентификация
- `POST /registration` - регистрация нового пользователя
- `POST /login` - вход в систему
- `GET /logout` - выход из системы
- `GET /refresh` - обновление токена

#### Ученики
- `GET /student` - страница ученика
- `POST /homework/send` - отправка домашнего задания
- `GET /homework/subject` - получение предметов для ДЗ
- `GET /homework/date` - получение дат для ДЗ

#### Классные руководители
- `GET /leader` - страница классного руководителя
- `POST /event` - создание события
- `POST /notification` - отправка уведомления
- `GET /checkmodal` - получение непроверенных ДЗ
- `POST /checkmodal/add` - проверка ДЗ (одобрение)
- `POST /checkmodal/del` - удаление ДЗ
- `POST /checkmodal/ban` - бан ученика и удаление ДЗ

#### Администраторы
- `GET /admin` - главная страница администратора
- `POST /admin/users/find` - поиск пользователя
- `POST /admin/users/load` - загрузка пользователей из файла
- `POST /admin/teacher/add` - добавление учителя
- `POST /admin/timetable/change` - изменение расписания
- И многие другие...

#### Общие страницы
- `GET /rating` - страница рейтингов
- `GET /schedule` - расписание
- `GET /map` - карта лицея
- `GET /help` - страница помощи
- `GET /info` - информация
- `GET /subject` - предметы

## 📊 Модели данных

### User (Пользователь)
- `name` - имя
- `surname` - фамилия
- `login` - логин
- `password` - хешированный пароль
- `class` - класс
- `status` - статус (admin, leader, student)
- `rating` - рейтинг
- `ban` - дата окончания бана
- `isChangePass` - флаг смены пароля

### Teacher (Учитель)
- `name` - имя
- `surname` - фамилия
- `lastname` - отчество
- `subjects` - массив предметов
- `classroom` - кабинет
- `students` - объект со студентами

### Hometask (Домашнее задание)
- `surname` - фамилия ученика
- `text` - текст задания
- `class` - класс
- `subject` - предмет
- `date` - дата
- `file` - путь к файлу
- `proved` - проверено ли

## 🔒 Безопасность

- Все пароли хешируются с использованием bcrypt
- Используется JWT для аутентификации
- Middleware для проверки авторизации
- Защита от CSRF
- Валидация всех входящих данных
- Cookie-based сессии
