## 📖 Описание

Веб-приложение для управления учебным процессом в лицее. Система предоставляет инструменты для администраторов, старост и учеников для управления расписанием, домашними заданиями, рейтингами и другими аспектами учебного процесса.


Мы столкнулись с проблемой, что учителя не всегда выкладывают домашнее задание, которое они озвучили на уроке, в сетевой журнал. И придумали свое решение этой проблемы. BL-school — это полнофункциональная платформа для управления учебным процессом в лицее. Главная концепция нашей реализации в том, что ученики сами загружают домашнее задание, которое они услышали. Старосты классов модерируют, что пишут школьники, и добавляют их домашние задания. Активность учеников отслеживается и формируется рейтинг, на основе которого можно реализовать поощерения, самым активным, тем самым мотивируя других.

Она в себя включает:
- Систему управления пользователями (администраторы, старосты, ученики)
- Управление расписанием уроков
- Систему домашних заданий с возможностью загрузки файлов от учеников
- Рейтинговую систему на основе активности учеников
- Систему уведомлений и событий для администраторов и старост
- Управление учителями и предметами
- Интерактивную карту лицея



## ✨ Основные возможности

### Для администраторов
- Управление пользователями (добавление, удаление, изменение)
- Массовая загрузка пользователей из файлов

## 🚀 Установка и запуск

### Предварительные требования

- Node.js (версия 14 или выше)
- MongoDB (версия 5 или выше)
- npm или yarn

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Rimashi/project_for_liceum.git
cd project_for_liceum
```

2. Установите зависимости:
```bash
npm install
```

### Настройка переменных окружения

Создайте файл `.env` в корне проекта и добавьте следующие переменные:
```env
PORT=3000
JWT_ACCESS_TOKEN=your_secret_access_token
JWT_REFRESH_TOKEN=your_secret_refresh_token
ADMIN_PASS=your_admin_password
```

### Запуск в режиме разработки

```bash
npm run dev
```

Убедитесь, что MongoDB запущен:
```bash
# Для Linux/MacOS
sudo systemctl start mongodb

# Для Windows
net start MongoDB
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Сборка для продакшена

```bash
npm start
```

## 🔧 Конфигурация

### Настройка базы данных

По умолчанию приложение подключается к локальной MongoDB:
```javascript
const url = 'mongodb://127.0.0.1:27017/liceum-app';
```

Если вы хотите использовать другую базу данных, измените строку подключения в файле `server.js`.

### Создание администратора

При первом запуске приложение автоматически создает пользователя `admin` с паролем, указанным в файле `.env` (переменная `ADMIN_PASS`).

Логин: `admin`  
Пароль: значение из `ADMIN_PASS` в `.env`



## 🚀 Использование

### Вход в систему

1. Откройте главную страницу (`http://localhost:3000`)
2. Введите логин и пароль
3. В зависимости от роли, вы будете перенаправлены на соответствующую страницу:
   - Администратор → `/admin`
   - Староста → `/leader`
   - Ученик → `/student`

### API

#### Аутентификация
- `POST /registration` - регистрация нового пользователя
- `POST /login` - вход в систему
- `GET /logout` - выход из системы
- `GET /refresh` - обновление токена

#### Ученики
- `GET /student` - страница ученика
- `POST /homework/send` - отправка домашнего задания
- `GET /homework/subject` - получение предметов для ДЗ
- `GET /homework/date` - получение дат для ДЗ

#### Старосты
- `GET /leader` - страница старосты
- `POST /event` - создание события
- `POST /notification` - отправка уведомления
- `GET /checkmodal` - получение непроверенных ДЗ
- `POST /checkmodal/add` - проверка ДЗ (одобрение)
- `POST /checkmodal/del` - удаление ДЗ
- `POST /checkmodal/ban` - бан ученика и удаление ДЗ

#### Администраторы
- `GET /admin` - главная страница администратора
- `POST /admin/users/find` - поиск пользователя
- `POST /admin/users/load` - загрузка пользователей из файла
- `POST /admin/teacher/add` - добавление учителя
- `POST /admin/timetable/change` - изменение расписания

#### Общие страницы
- `GET /rating` - страница рейтингов
- `GET /schedule` - расписание
- `GET /map` - карта лицея
- `GET /help` - страница помощи
- `GET /info` - информация
- `GET /subject` - предметы



## 🔒 Безопасность

- Все пароли хешируются с использованием bcrypt
- Используется JWT для аутентификации
- Middleware для проверки авторизации
- Защита от CSRF
- Валидация всех входящих данных
- Cookie-based сессии
